# Install CinterForge Terminal

## macOS

1. Drag **CinterForge Terminal.app** onto the **Applications** shortcut.
2. Open CinterForge Terminal from Applications.
3. If macOS requests permission to open a downloaded app or access files,
   review the request in the normal macOS interface.

## Windows

1. Run the **CinterForgeTerminal-win.msi** installer.
2. Open **CinterForge Terminal** from the Start menu.
3. You can change or uninstall the app from Windows' Installed Apps settings.

## DevTools

The Terminal application runs without Steam. CinterForge DevTools are optional
and installed separately when you choose to install developer tools.

For information and support, visit https://www.cinterforge.com/.
